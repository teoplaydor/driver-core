# Секретарь — Android, без сервера (2.x)

Приложение «Секретарь» (`local.secretary`), доработанное так, чтобы сервер был не нужен. Раньше оно читало
уведомления и отправляло их на сервер (Python + Gemini), а тот разбирал, решал и присылал ответы. Теперь вся
серверная логика работает в самом телефоне, а нейросеть — **Gemini напрямую с телефона по своему API-ключу**,
вписанному в приложении.

Всё остальное — как было:

- уведомления читаются целиком и разбираются по чатам, когда в чате пауза: карточка, срочное — сразу;
- «Тишина»: «Не беспокоить» + важное со звуком копией оригинала (его значок и кнопки), реклама убирается;
- дела и «Сделал?» при разблокировке (Сделал / Отложить / Принял), закрытие дел по уликам;
- расходы по уведомлениям банков, сводки утром и вечером, напоминания и «через 10 минут» о занятиях;
- чат с секретарём (та же страница `app.html`), голосовые — распознаёт Gemini;
- те же промпты, те же модели (быстрая — сортировка, умная — разговор и черновики, голос), та же база SQLite.

Не перенесено (жило только на сервере): почта по IMAP и Telegram-бот.

## Настройка

«⋮ → Настройка» (при первом запуске само попросит ключ):

| Пункт | Было в `config.toml` |
|---|---|
| 🔑 Ключ Gemini (aistudio.google.com → Get API key), «Сохранить и проверить» | `[llm] gemini_api_key` |
| 🤖 Модели: `gemini:…` или `openai:…`, размышления, ключ и адрес OpenAI-совместимого API | `fast_model`, `smart_model`, `audio_model`, `gemini_thinking`, `openai_*` |
| 👤 О себе | `about_me` |
| ✍️ Подпись | `my_name` |
| 🗓 Сводки и напоминания до событий | `digest_times`, `remind_before_minutes` |
| 📜 Отправить журнал | — |

Если Gemini отвечает «location is not supported» — запрос идёт с российского IP: нужен VPN на телефоне
(серверные обходы через DoH и прокси здесь не нужны).

Журнал (`files/journal.txt`, «Отправить журнал» кладёт его в Documents/Секретарь) пишет, что секретарь делал и
почему: каждое уведомление (приложение, чат, сколько сообщений — без текста), решения «Тишины», запросы к Gemini
(модель, время, ответ), будильники, ошибки со стеком.

## Как устроено

- `src/local/secretary/` — приложение: `Listener` (уведомления, «Тишина»), `Tasks` («Сделал?»),
  `SnoozeActivity`, `MainActivity` (чат, настройка, голос), `Queue` — как было; `Net` теперь отвечает на прежние
  адреса сервера (`/hook/phone`, `/api/...`) внутри приложения; `Core` — секретарь, Gemini, база, циклы
  (чаты каждые 20 с, расписание каждые 30 с), точный будильник, журнал.
- Логика секретаря — общий код с SemSearch: `../gemma-search-android/src/io/github/teoplaydor/semsearch/secretary/`
  (перенос `phone.py`, `triage.py`, `tasks.py`, `finance.py`, `digest.py`, `assistant.py`, `actions.py`, `webapp.py`,
  `db.py`, промпты слово в слово; `GeminiBrain` — `llm.py`). Его тесты: серверные pytest, перенесённые на Java
  (`../gemma-search-android/test/secretary/SecretaryTest.java`), и `GeminiBrainTest` против подставного Gemini.
- `test/AppTest.java` — приложение целиком на Robolectric (Android 14) с подставным Gemini: `test/run.sh`.

## Сборка

```
bash secretary-android/build.sh
```

Инструменты — как раньше в `~/.secretary-android` (build-tools 35, android-35, JDK, `release.jks`); чего нет,
берётся из системы или скачивается с Google (android.jar, d8). Собранное своим `release.jks` встаёт поверх прежней
версии; собранное с новым ключом — только после удаления старой.
