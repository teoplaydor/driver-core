# Cozy World

Уютный 3D-мир в браузере: заходишь по ссылке на комнату, гуляешь с друзьями по мультяшному лесу, садишься у костра,
играешь в шахматы в беседке, бросаешься мячами и болтаешь голосом — чем дальше человек, тем тише его слышно.
Работает на компьютере (вид от первого лица, WASD + мышь) и на телефоне (джойстик и кнопки).

Стиль вдохновлён *RV There Yet?*: насыщенные цвета, пухлые «бобовые» человечки с большими головами, огромные руки от
первого лица, painterly-ёлки и оранжевые каньоны.

## Что уже есть

- **Мир** (~490×490 м): луг с костром и беседкой, озеро с пирсом, осенний лес с фермой, зимний лес с домиком,
  дождливый район с многоэтажкой, оранжевый каньон и белая арена. Туман, небо с облаками, свет и звук плавно меняются
  от зоны к зоне; идёт дождь, снег и падают листья.
- **Персонажи**: кастомизация (кожа, одежда, шляпа, очки, волосы), анимация ходьбы/прыжка/приветствия, ник над головой,
  пузырь с сообщением.
- **Комнаты**: заходишь по коду или ссылке `?room=код`, до 16 человек в комнате, чат, приветствие (X).
- **Предметы**: взять (E), поставить, бросить (Q, удерживай — сильнее); мячи, ящики, кружки, мягкие дубинки и полный
  набор шахмат — фигуры сами встают по центру клетки. Состояние предметов синхронизируется между игроками.
- **Голос по расстоянию** (V): WebRTC между игроками, объёмный звук (слышно, откуда говорят).
- **Квартира**: дверь в многоэтажке ведёт внутрь — тёплая комната, за окном идёт дождь.
- **Звук без файлов**: ветер, дождь, костёр, птицы, озеро, шаги по траве/тропе/снегу/воде/дереву — всё синтезируется.
- **Телефон**: джойстик, свайп для обзора, кнопки прыжка/взять/бросить/чат/микрофон/звук.

## Управление

| Действие | ПК | Телефон |
| --- | --- | --- |
| Ходить / бежать | WASD / Shift | джойстик / ⚡ |
| Обзор | мышь | свайп по правой части экрана |
| Прыжок | Пробел | ⤒ |
| Взять / поставить / использовать дверь | E или ЛКМ | ✋ или тап по экрану |
| Бросить (держи — сильнее) | Q | ↗ |
| Помахать | X | 👋 |
| Микрофон | V | 🎤 |
| Чат | T или Enter | 💬 |
| Вид от 3-го лица | C | 📷 |
| Звук вкл/выкл | M | 🔊 |
| Кто в комнате | Tab | — |

## Запуск

Нужен Node.js 20+.

```bash
cd cozy-world
npm install
npm run dev          # http://localhost:5173 — клиент и игровой сервер в одном процессе
```

Комната создаётся автоматически; ссылку на неё можно скопировать кнопкой «Ссылка» в углу экрана. Если сервер
недоступен, игра сама переходит в одиночный режим.

Боевая сборка:

```bash
npm run build
PORT=3000 npm start  # раздаёт dist/ и держит WebSocket на /ws
```

Проверка: `GET /health` отдаёт `{"ok":true,"rooms":N,"players":M}`.

## Выкладка на свой сервер (например, Beget VPS + поддомен)

Нужен именно **VPS** (или любой сервер, где можно держать долгоживущий процесс Node.js с WebSocket). Обычный
виртуальный хостинг для сайтов под это не подходит.

1. Создай A-запись поддомена (например `play.твойдомен.ru`) на IP сервера.
2. На сервере: Node.js 20+, nginx, certbot.
3. Залей проект в `/opt/cozy-world`, затем `npm ci && npm run build`.
4. Положи `deploy/cozy-world.service` в `/etc/systemd/system/`, включи: `systemctl enable --now cozy-world`.
5. Положи `deploy/nginx.conf` в `/etc/nginx/sites-available/` (поправь `server_name`), включи, перезапусти nginx.
6. Выпусти сертификат: `certbot --nginx -d play.твойдомен.ru`. **HTTPS обязателен** — без него браузер не даст доступ
   к микрофону.
7. Для голоса у людей за «жёстким» NAT нужен TURN-сервер. Поставь `coturn` по примеру `deploy/turnserver.conf` и
   передай адреса серверу: `ICE_SERVERS='[{"urls":"stun:stun.l.google.com:19302"},{"urls":"turn:play.твойдомен.ru:3478","username":"cozy","credential":"пароль"}]'`
   (переменная окружения в `cozy-world.service`). Без TURN голос работает у большинства, но не у всех.

> Эти шаги не проверялись на конкретном хостинге: проверено, что сборка и сервер работают локально, включая
> раздачу `dist/` и WebSocket.

## Как устроено

```
cozy-world/
├── src/
│   ├── main.js, game.js        цикл кадров, меню → игра, комнаты, переподключение
│   ├── world/                  рельеф, небо/свет/туман по зонам, растительность, трава, постройки,
│   │                           предметы и их физика, погода, коллизии
│   ├── player/                 ввод (клавиатура/мышь/тач), контроллер, аватар, руки от первого лица
│   ├── net/                    WebSocket-клиент, интерполяция чужих игроков, голос (WebRTC)
│   ├── audio/engine.js         синтез звука (WebAudio)
│   └── ui/                     HTML-интерфейс
├── server/                     игровой сервер (ws) + раздача dist/
├── shared/                     раскладка и список предметов — общие для клиента и сервера
├── deploy/                     nginx, systemd, coturn
└── tests/                      проверки в headless-Chromium
```

**Сеть.** Клиент сам считает свою позицию и шлёт её ~15 раз в секунду; сервер проверяет формат и частоту, собирает
снапшоты и рассылает. Предметами в каждый момент «владеет» один игрок: он считает физику и шлёт состояние, остальные
плавно догоняют; когда предмет успокоился, владелец объявляет покой. Голос идёт напрямую между игроками, сервер
пересылает только сигнальные сообщения.

**Мир одинаков у всех** без пересылки: рельеф, деревья и трава генерируются из фиксированных зерён.

## Проверки

Нужен запущенный сервер (`npm run dev`) и Chromium (в окружении Playwright он уже есть):

```bash
node tests/physics.mjs   # физика предметов, шахматные клетки
node tests/multi.mjs     # два клиента: комната, чат, предметы, голос
node tests/touch.mjs     # эмуляция телефона: джойстик, обзор, прыжок
node tests/tour.mjs      # скриншоты зон → tests/out/tour-*.png
```
