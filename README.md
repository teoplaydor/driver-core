# DriverCore

Лёгкая утилита для Windows, которая «из коробки» проверяет **всё оборудование**
компьютера, находит устройства без драйверов и помогает доустановить недостающие
драйверы и системные компоненты — без танцев с бубном. Тёмная **кофейная** тема,
прогресс-бары, всё на русском.

> Платформа: **.NET Framework 4.8** (WinForms). Этот рантайм уже встроен в Windows 10
> (1903+) и Windows 11, поэтому `DriverCore.exe` запускается на любой свежей системе
> без установки чего-либо. Один файл, никаких сторонних DLL.

## Что умеет

- **Полная проверка железа** через WMI: процессор, видеокарта, память, накопители
  (SSD/HDD/NVMe), сеть, звук, материнская плата, BIOS/UEFI, мониторы, USB —
  и **все** PnP-устройства для поиска проблем.
- **Поиск проблемных устройств**: расшифровывает коды диспетчера устройств
  (`ConfigManagerErrorCode`) — «нет драйвера» (код 28), «отключено» (22) и т.д.
- **Обновление драйверов** через официальный агент **Windows Update** (WUApiLib),
  включая драйверы видеокарты (WHQL). Никаких сторонних «драйвер-паков».
- **Видеокарты**: определяет производителя (NVIDIA / AMD / Intel) по PCI-ID и даёт
  ссылку на официальный сайт драйверов для свежих игровых версий.
- **Компоненты и доп. софт** (галочки, тихая установка, прогресс по каждому):
  - Visual C++ 2015–2022 Redistributable (x64 и x86) — C/C++ библиотеки;
  - DirectX Runtime (June 2010 / D3DX) — для игр;
  - .NET 8 Desktop Runtime (x64).
  Все ссылки — только официальные Microsoft. Уже установленные компоненты
  определяются и не ставятся повторно.
- **Кофейная тёмная тема**: эспрессо-фон, латте-поверхности, карамельные акценты,
  кремовый текст; кастомное безрамочное окно, скруглённые прогресс-бары,
  тёмная таблица оборудования.

## Запуск

1. Запустите `DriverCore.exe` (папка `bin\Release\net48`).
2. Приложение **сразу** проверяет компьютер и показывает сводку.
3. Для установки драйверов/компонентов нужны права администратора — программа
   попросит повышение прав (UAC) только в момент установки. Само сканирование
   работает без админ-прав.

## Сборка из исходников

Нужен .NET SDK (8.x). MSBuild/Visual Studio не обязателен.

```powershell
dotnet build DriverCore.csproj -c Release
```

На выходе — `bin\Release\net48\DriverCore.exe`.

## Скрытые режимы (для диагностики)

```powershell
DriverCore.exe --scan            # консольный самотест сканера, отчёт в %TEMP%\drivercore-scan.txt
DriverCore.exe --shot <папка>    # рендер всех вкладок в PNG (без интерактива)
```

## Честные оговорки

- Обновление драйверов через Windows Update может быть **ограничено политикой**
  (WSUS / Intune / лимитное подключение). В таком случае программа честно об этом
  сообщает, а для видеокарты предлагает официальный сайт производителя.
- Точного публичного API «дай самый свежий драйвер для этой видеокарты» у вендоров
  нет, поэтому для последних игровых драйверов — ссылка на официальный сайт
  (открывается в браузере, ничего не качается тайком).
- DirectX тянется прямой ссылкой на `dxwebsetup.exe`; если она недоступна,
  открывается официальная страница загрузки Microsoft.
- Никаких сторонних драйвер-паков, рекламы и «лишнего» софта — только официальные
  дистрибутивы Microsoft.

## Структура проекта

```
DriverCore.csproj      — SDK-style проект, target net48, WinForms
app.manifest           — DPI-awareness, совместимость с Win7–11, asInvoker
Program.cs             — точка входа (+ режимы --scan / --shot)
Theme/                 — палитра, шрифты, WinAPI (тёмные элементы, скругление углов)
Controls/              — кастомные контролы (окно, кнопки, прогресс, чекбоксы, карточки)
Models/                — модели (устройства, инвентарь, компоненты)
Services/              — WMI-сканер, проверка/установка компонентов, драйверы (WUApiLib), загрузка
UI/                    — MainForm и панели (Обзор, Оборудование, Драйверы, Компоненты)
```
